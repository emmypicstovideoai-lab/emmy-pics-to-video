# 🎬 Emmy Pics to Video AI

> **Turn your pictures into AI-generated videos.**

Emmy Pics to Video AI is a modern web app that lets users upload a picture, describe the video they want, and receive an AI-generated video. Currently in **testing mode** — real AI video generation is coming soon.

---

## ✨ Features

- 🔐 **User accounts** — sign up, log in, and verify email
- 🔁 **Password recovery** — reset via secure email link
- 🎨 **Modern UI** — purple-themed, mobile-friendly design
- 📸 **Image upload** — upload a picture with preview
- ✍️ **Prompt input** — describe the motion you want in the video
- 🗂️ **My Videos** — view all your previous requests
- 🔒 **Data isolation** — each user only sees their own videos
- 🧪 **Testing mode** — requests saved to database, ready for AI integration
